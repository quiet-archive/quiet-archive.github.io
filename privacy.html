Privacy Policy

Last updated: November 17, 2026

Purpose

Quiet Archive is a personal backup setup that uses rclone to copy Google Drive files to a local computer.

Data Access and Use

The utility accesses Google Drive files using read-only authorization. File contents and metadata are used solely for personal backup purposes.

Data Storage

Backup files are stored locally on a computer controlled by the user. OAuth credentials are stored locally for authentication.

Data Sharing

The utility does not intentionally share Google Drive file contents with third parties. It is not offered as a public service.

Data Retention

Local backup files are retained until the user chooses to remove them. Google Drive access can be revoked through Google Account settings.

Contact

This is a private, owner-operated utility. It is not available for public registration.
